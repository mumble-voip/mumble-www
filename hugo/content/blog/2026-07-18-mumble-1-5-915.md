Today we release the fourth patch release in the Mumble 1.5.x series. This patch is smaller in size, but
contains some important server-side fixes. We are unable to provide new pre-compiled macOS binaries for the 1.5 series.
Please read this blog post for more information.

You can download the new version from our [**Downloads page**]({{< relref "/downloads" >}}) or the
[**GitHub release page**](https://github.com/mumble-voip/mumble/releases/tag/v1.5.915) or from within your Windows client or software package
management system.

<!--more-->

## macOS Binaries

We can no longer provide pre-compiled macOS binaries for the Mumble 1.5 series. This is because our build machine was upgraded
to macOS 26 Tahoe, which dropped the AGL framework entirely from the macOS SDK. AGL, however, is a hard dependency for Qt 5 on macOS.
We are not going to port the 1.5.x branch to Qt6 - that has already happenend for the upcoming Mumble 1.6 series - and we
can not downgrade the build system. We have no option but to stop providing pre-compiled binaries for the Mumble 1.5 series on macOS.
