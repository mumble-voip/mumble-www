Today we release the third patch release in the Mumble 1.5.x series. We have fixed a long standing
issue with analog input devices such as racing wheels causing Mumble to hang!

You can download the new version from our [**Downloads page**]({{< relref "/downloads" >}}) or the
[**GitHub release page**](https://github.com/mumble-voip/mumble/releases/tag/v1.5.901) or from within your Windows client or software package
management system.

<!--more-->

## Changelog

This is the full list of changes since Mumble version 1.5.857.

### Client

- Fixed: Crash when invalid varint encodings are parsed ({{< issue 7148 >}})
- Fixed: Don't send placeholder when using paste+send, if window is out-of-focus ({{< issue 7121 >}})
- Fixed: Ensure we never write to an invalid socket ({{< issue 7168 >}})
- Fixed: Explicitly request accessibility permissions on macOS ({{< issue 7041 >}})
- Fixed: Hangs from input events caused by analog input devices such as racing wheels ({{< issue 6696 >}})
- Fixed: Opus related out-of-bounds memory access **CVE-2025-71264** ({{< issue 7033 >}})

### Server

- Fixed: Crash when invalid varint encodings are parsed ({{< issue 7148 >}})
- Fixed: Ensure we never write to an invalid socket ({{< issue 7168 >}})
- Fixed: First audio packet for new whisper getting dropped ({{< issue 7177 >}})
- Fixed: Rare crash caused by negative public server list registration timer ({{< issue 6959 >}})

### Miscellaneous

- Fixed: Rare buffer overflow in Mumble overlay ({{< issue 6990 >}})
- Fixed: Windows installer quitting prematurely, if newer version of VC_redist is already installed ({{< issue 7086 >}})

## Known issues

- Windows server crashing when ``bonjour`` option is enabled. Disable this option for now to fix the crash ({{< issue 7071 >}})
- macOS binaries not being signed/notarized (overlay installer not signed) ({{< issue 4263 >}})
- Overlay blocked by CS:GO Trusted Mode
