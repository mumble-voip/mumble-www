We are happy to announce the second release candidate of the next Mumble stable series: version 1.6.
We want to get this stable as soon as possible, so please make sure
to report any issues you encounter in our [**GitHub issue tracker**](https://github.com/mumble-voip/mumble/issues).

For the first time we are including macOS arm64 pre-built binaries for this release.

You can download the new version from our [**Downloads page**]({{< relref "/downloads" >}}) or the
[**GitHub release page**](https://github.com/mumble-voip/mumble/releases/tag/v1.6.0-alpha2) or from within your Windows client or software package
management system.

<!--more-->

## macOS arm64

We are including macOS arm64 binaries in this release for the first time. Please let us know, if they
work as intended. macOS binaries are still not signed nor notarized and this will not change for the
foreseeable future.
