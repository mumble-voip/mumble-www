Today we release the fifth patch release in the Mumble 1.5.x series. This patch contains a few
important bug fixes. Especially server administrators should update to this patch level.

You can download the new version from our [**Downloads page**]({{< relref "/downloads" >}}) or the
[**GitHub release page**](https://github.com/mumble-voip/mumble/releases/tag/v1.5.939) or from within your Windows client or software package
management system.

<!--more-->

We are unable to provide macOS binaries. See the [previous blog post]({{< relref "/blog/2026-07-18-mumble-1-5-915" >}}) for more information.

## Changelog

This is the full list of changes since Mumble version 1.5.915.

### Client

- Fixed: Rare library loading issue ({{< issue 7324 >}})
- Fixed: Skip UDP ping when TCP mode is forced ({{< issue 7302 >}})

### Server

- Fixed: Disallow data flow to and from unauthenticated connections ({{< issue 7398 >}})
- Fixed: Password generator not using the full alphabet ({{< issue 7313 >}})
- Fixed: Various server-side bug fixes which could lead to crashes or denial-of-service ({{< issue 7398 >}})

### Both

- Fixed: IP netmask handling ({{< issue 7283 >}})
- Fixed: Network Quality of Service setting with IPv6 ({{< issue 7345 >}})
- Fixed: Versioning scheme on Windows 10 (21H1) or greater ({{< issue 7263 >}})

### Miscellaneous

- Fixed: Various build issues under many different toolchain configurations

## Known issues

- Overlay blocked by CS:GO Trusted Mode
